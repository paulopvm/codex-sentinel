# Melhorias futuras / Roadmap

Estas são oportunidades de contribuição, não funcionalidades já entregues ou
promessas com prazo. Abra uma issue antes de uma mudança grande.

- **Distribuição Apple:** assinatura Developer ID e notarização para facilitar
  abertura em outros Macs. Exigem conta e credenciais Apple do mantenedor.
- **Compatibilidade:** testar em Macs Intel e macOS 14, registrar versões do CLI
  e desktop e adicionar testes para variações do protocolo.
- **Internacionalização:** interface em inglês e catálogo de strings. A UI atual
  está em português; o guia de instalação já existe em inglês.
- **Acessibilidade:** testes de VoiceOver, contraste, texto maior e navegação por teclado.
- **Instalação:** após distribuição universal estável, avaliar Homebrew.
- **Integração:** reduzir dependência do IPC interno se uma API oficial do desktop
  oferecer a mesma capacidade.
- **Diagnóstico:** exportação explícita de diagnóstico com remoção de dados pessoais.

Contribuições devem manter o app local, sem telemetria, com retomada opcional e
bloqueios conservadores. Veja [CONTRIBUTING.md](../CONTRIBUTING.md).
